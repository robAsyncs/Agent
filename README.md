#LangGraph Agent#

A stateful AI agent built with LangGraph and the OpenAI API, designed to explore how modern agentic systems reason, use tools, maintain state, and iteratively complete tasks.

Overview

This project implements an AI agent using a graph-based architecture. Unlike a traditional chatbot that generates a single response to a user prompt, the agent can determine when it needs additional information, invoke tools, process their results, and continue reasoning until it reaches a final answer.

The project is primarily focused on understanding the engineering principles behind agentic systems, including:

LLM-driven decision making
Tool and function calling
Agent loops
Stateful execution
Tool result handling
Conditional workflows
Error handling and retries
Agent observability and evaluation
